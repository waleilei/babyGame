# 0005 重画生成的人物锚定策略

日期：2026-10-21　状态：已接受

## 背景

2026-10-21 三口径抽检（`reports/consistency-sample-audit-2026-10-21.md`，ticket 134）：40 张未处理章的存量图里，内容一致 24/44 需重画，外推全书约 280-300 张待重画。其中「人物一致」呈**系统性轻度漂移**——妈妈袖长、发色（黑↔棕）、宝宝发型发色、玩偶造型在同组四张内不齐；116 组另出现月龄崩（116-2）与设定外孕妇体型（116-4）。

逐格重画治不了这类漂移：每格独立生成时，文字提示词对人物细节（袖长、发色、玩偶样式）的服从度不足，同一句人物层文本四次生成得到四个人。抽检里 065 全过说明文字层能做到的下限，但上限受生成随机性限制。

## 决定

1. **重画一律参考图锚定**：每格生成时附一张参考图作为人物与画风锚定。选图顺序：
   - 首选同组已判 pass 的格（同一游戏四格里已合格的那张）；
   - 同组无 pass 时，用同章最近一次通过风格校准门（calibration.md 裁决：吉卜力动画面部）的成图；
   - 都没有时，用 `calibration/001-1-calibration.jpg` 之后的最新校准通过图。
2. **参考图只锚人物与画风，不锚构图**：动作、镜头、场景仍以该格提示词为准；参考图与提示词冲突时提示词优先（权威顺序见 ADR-0003）。
3. **不把一致性寄托在种子上**：当前生成通道未提供可控、可复现的种子参数，若日后通道提供，可作为补充手段修订本 ADR，但在此之前参考图是唯一锚定依据。
4. **串行与记账纪律不变**：沿用 ADR-0004 的串行生成、指纹备份、≤2 次重试、needs-human 兜底与双仓回写。
5. **锚定来源记进批次记录**：每行台账在盲审记录中注明参考图 key，使「这张图的人物像谁」可追溯。

## 后果

- 人物漂移有可执行的收敛手段，但参考图会引入构图干扰风险：盲审时须把「被参考图带偏的动作/场景」列为例行检查项。
- 同组四张的生成顺序变为「先 pass 一张，再锚它生成其余三张」，与既有整组判定、整组验收的单位一致。
- 提示词改动仍会使台账 `prompt_hash` 过期，本决定不改变任何校验接缝。
