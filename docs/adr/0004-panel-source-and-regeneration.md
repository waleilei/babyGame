# 0004 步骤图的来源与重生成口径

日期：2026-10-20　状态：已接受

## 背景

520 张步骤图由已归档的旧总表生成（证据：`tmp/fix` 文件名措辞、058-3 的猫、036-1 的绕珠玩具），现行分层提示词从未用于出图。2026-10 起按章重画对齐。

## 决定

1. **重画门槛**：只改与提示词/正文冲突的格子（理由码 A1–A6），不为审美重画。
2. **风格口径（Q15=B）**：以现有 520 张的吉卜力式动画面部为准——人物层加「面部为吉卜力式动画画法，杏圆大眼」，负面层禁「写实人脸」，原「动漫大眼」禁令撤销。
3. **批处理纪律**：一章一泳道；单批重画 ≤10 张；覆盖前按指纹备份，无备份不覆盖；单格最多两次尝试，仍败转 `needs-human`（作者可追加机会）。
4. **已知偏离（追认）**：
   - 月龄姿态锁定句：对 0-3 月高风险格在逐字拼接文案外追加姿态锁定与对应负面词；
   - 生成串行化：image_gen 并行写盘会串写结果，一律一格一次；
   - pass 行携带 `new_sha256`（磁盘原图指纹），只禁 `old_sha256`。
5. **回写**：定稿必须同时落 babyGame `panel_web/*.jpg` 与书稿仓 `panel/NNN-K.png` + `panel_web/NNN-K.jpg`，否则 `npm run data` 会用书稿旧图覆盖重画成果（ch05 已发生一次，见 `batches/ch05.md`）。新 PNG 为 1152×768（3:2），不再强行 1536×1024。

## 后果

- 提示词一改，台账 `prompt_hash` 过期，该格必须重新比对。
- 风格层改动波及全部 520 条，改后必须重新校准 1 张并抽查。

## 一致性三要素（2026-10-20 补，重画执行的硬约束）

**角色特征**：唯一来源是人物层模板，逐字进每条提示词。A 级硬约束=面部画法（吉卜力式动画、杏圆大眼）、服装（妈妈砖红上衣+米色长裙；宝宝米色连体衣、赤脚）、月龄运动边界（0-3 月躺/被抱；4-6 月禁独坐/爬/站；7-9 月禁独走；逐章递进）。多人物动作由代码自动补「其他人物同色系低饱和」。衣色等轻微漂移记 B，同一偏差连续两章复现升 A。

**场景连贯性**：四个判定维度——场景 id 与格层一致；同游戏四格场景连贯（家具/地面/光位不跳变），除非正文步骤明确换场景；格内无提示词外的主要陈设；道具与背景陈设以提示词和场景字典 full 文案为白名单。

**偏离处理**：生成必须串行（并行写盘会串图），落盘后指纹查重，重复即废；A 级重画 ≤2 次，仍败转 needs-human（旧图有指纹备份、历次 PNG 留档）；无备份不覆盖；定稿双仓回写；台账 prompt_hash 过期即强制重新比对。
