# 0003 提示词与画面的权威顺序

日期：2026-10-20　状态：已接受

## 决定

**正文 > 插画脚本 > 数据 > 现有图片。**

- 提示词与正文冲突时，先改提示词再改图；数据与正文冲突是抽取 bug，单独修抽取，不用提示词掩盖。
- 图片不是事实来源，只作风格与构图参考。
- 逐格判定分三级：A 事实冲突（月龄/道具/场景/动作错位/违反安全条）必修；B 关键语义缺漏（缺了会画错）择要补；C 措辞与构图差异不动。

## 后果

- 提示词改动必须能回溯到正文行号，证据不足不改。
- 由正文步骤改写的约 20 个游戏是偏差高发区，优先复核。
- 本轮 520 条逐格复核由模型完成，不代替人工签字；台账 `reports/panel-ledger/` 保留逐格证据供抽查。
