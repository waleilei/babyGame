# 02: 风格校准门

**What to build:** 在铺开 130 个游戏之前，先证明新生成的图能放进同一本书：挑一个场景最典型、元素最少的格子，按共享层逐字生成 1 张，与同场景现有图并排比对，给出「可用 / 不可用」与具体差异点。不可用时整条流水线停下等人判断，不产生任何覆盖。

**Blocked by:** 01（清单、备份与校验接缝）

**Status:** ready-for-human

- [ ] 生成 1 张校准图，3:2 画幅，落在临时位，不覆盖任何现有图
- [ ] 与现有图并排比对 5 项：色调、水彩纸纹、轮廓线、人物面部与手部、光位
- [ ] 通过：记录生成参数（模型、风格前缀、负面层），后续所有批次只能用这套参数
- [ ] 不通过：写明差异点，把全部游戏 ticket 标 blocked，交人决定是否更换生成方式
- [ ] 校准结论写入本批记录，可被后续批次引用

## Comments

- 2026-10-20 完成试画：001-1 按拼接文案逐字生成，1152×768 → 900×600 JPG（176 KB）。内容五项全命中，道具数量甚至优于现有图（旧图只画 1 张卡）。
- 关键发现：现有 520 张是动画面部（吉卜力式），而共享负面层禁「动漫大眼」——现有图与现行风格层本身相抵触。新图服从现行提示词后，面部画法必然与旧图不同。结论与三个选项见 calibration.md，等拍板；未通过前 130 张游戏票全部保持 blocked，不覆盖任何现有图。
