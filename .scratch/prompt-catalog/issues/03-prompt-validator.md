# 03: 校验器

**What to build:** 一条校验命令对现有提示词目录给出可执行的判断：缺字段、未知镜头或场景、禁画项、月龄不符、超长、四格重复、场景与场地不符，各归错误或警告，并统计 `待复核` 数量。每条错误带步骤图编号，能直接跳到出问题的那一行。
