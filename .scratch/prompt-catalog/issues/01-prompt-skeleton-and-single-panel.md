# 01: 骨架与单格端到端

**What to build:** 从一份可编辑的提示词目录读出一条记录，按固定顺序拼成最终文案并打印出来。目录骨架、五个预设字典、被冻结的原总表、解析与组合的纯函数、命令行入口在这一票里一起就位，第一条真实数据用 006-3 验证。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] `npm run prompt 006-3` 输出一条完整文案，七层顺序为风格、人物、镜头、场景、动作、道具、负面
- [ ] `npm run prompt 006` 输出该游戏四条文案
- [ ] 不存在的编号以退出码 1 结束并提示
- [ ] 原总表已冻结入库，文件内注明只读
- [ ] 解析与组合是纯函数，合成夹具覆盖缺字段、未知镜头、未知场景、动作带句号
- [ ] 该模块的测试可单独运行且全绿
