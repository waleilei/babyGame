## Comments

根因不是窗口太短，而是判定维度选错了：用「距上次 Esc 过去多久」去猜「这是不是同一次 Esc」。任何窗口都只是把竞态挪个位置。

改为结构判定——大图在 `document` 捕获阶段吞掉 Esc：`preventDefault` 抑制浏览器派发 `cancel`，`stopPropagation` 让它到不了底层。大图一旦关闭，同一个处理器因 `!dialog.open` 立即失效，下一次 Esc 自然落到游戏详情。没有窗口，也没有 `setTimeout` 延后。

因此 retro 新增的 `src/domain/dialog-stack.js` 连同测试一并删除：时间窗口消失后，那个纯函数没有规则可表达了，留着是装饰。`game-dialog` 的 `isBlocked` 回调也随之下线。

验证方式：Chrome 155 + CDP 驱动真实按键，5 条路径全绿（单层关闭、卡片主图进入、第一次 Esc 只关大图、紧随其后的第二次 Esc 关详情、大图内 Esc 不切章）。
