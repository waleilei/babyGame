# 09: 图片大图查看

**What to build:** 卡片主图、详情弹层主图与 4 张步骤图都能点开大图；大图用原生 `<dialog>` 叠在游戏详情弹层之上，可缩放、拖拽平移、左右切换，关闭后焦点回到被点的图片，且不新增路由与历史项。

**Blocked by:** 04 游戏弹层与深链；07 手机/桌面适配与键盘可访问性

**Status:** done

- [x] 卡片主图可点；卡片拆成“图片按钮 + 详情按钮”，两者各有可访问名称，Tab 顺序为先图片后详情，不嵌套按钮
- [x] 弹层主图与 4 张步骤图可点；点哪张就从哪张开始
- [x] 大图在该游戏的 4 张步骤图之间左右切换（首张同时也是卡片/弹层主图），到首/末张即停，不跨游戏
- [x] 用原生 `<dialog>` 以 `showModal()` 叠在游戏详情弹层之上；打开与关闭都不改 URL、不写历史、不新增路由
- [x] 滚轮与双指缩放，范围 1–6 倍；1 倍时图片居中
- [x] 放大后可拖拽平移；切图后缩放与位移重置
- [x] 图片加载失败显示文字占位，不塌陷
- [x] `Esc` 只关闭大图层，游戏详情弹层保持打开、URL 不变；关闭后焦点回到被点的图片按钮
