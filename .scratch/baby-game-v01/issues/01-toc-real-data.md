# 01: 目录页用真实数据跑通

**What to build:** 打开应用即看到按“篇”分组的 14 个游戏章目录，每章显示章号、标题、月龄与游戏数；页面只加载目录数据，为后续按章加载建立壳与路由。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 从三份游戏章稿件提取出 2 个篇、14 个章、130 条游戏索引，游戏数合计 130
- [x] 目录按篇分组，顺序与书一致（第 5-12 章在前，第 13-18 章在后）
- [x] 每章显示章号、标题、月龄段、游戏数
- [x] 首屏只请求目录数据，不请求任何章节数据
- [x] 目录数据契约测试通过：章数、索引数、字段完整、章号唯一
- [x] 应用以相对路径部署到静态托管的子目录时仍能正常显示
