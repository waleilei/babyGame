# 01: 锚定执行规程

**What to build:** 让任何一个新接手的执行体拿一份规程就能把参考图锚定落进批次：开工前先以当日磁盘图重验受影响格子；每格按「同组 pass 格 → 同章最近校准通过图 → 最新校准通过图」选参考图，并把第三级落成具体的图片 key；整组先出一个 pass 再锚它出其余；参考图与提示词冲突时提示词优先。盲审把「被参考图带偏的动作/场景」列为例行检查项；每组并排按画风、人物、内容三口径过一遍，画风不符记 A7-style。规程同时定下出图任务单的固定字段，使不产图的准备票能交付出可直接执行的任务单。

**Blocked by:** None（可以立即开始）

**Status:** ready-for-human

- [ ] 规程能回答四个问题：开工前重验哪些格子、参考图三级选序（第三级指向具体图片 key）、整组生成顺序、参考图与提示词冲突时谁优先
- [ ] 出图任务单字段固定：key、提示词 hash、参考图 key、判定理由码、落图后的回填位置
- [ ] 盲审例检项含「被参考图带偏的动作/场景」；结论与台账不一致即转 needs-human
- [ ] 三口径并排验收步骤与 A7 记录口径写明，且不另立一套判定规则
- [ ] 既有批次 spec 与发布人工清单各有一个指针指向该规程，新接手从任一入口都能找到
- [ ] 纸面演练：116-2、116-3、116-4 各给出选中的参考图 key 与理由，不依赖生成
