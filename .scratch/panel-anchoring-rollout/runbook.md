# 锚定出图执行规程

**适用**：`.scratch/panel-prompt-alignment/` 的批次流程，2026-10-21 起的所有步骤图重画批次。
**依据**：ADR-0005（为什么用参考图）、ADR-0004（批次纪律与双仓回写）、GLOSSARY 三口径（画风 / 人物 / 内容一致）。
**读者**：接批次任务的执行体、盲审者、作者。

每格出图时附一张参考图锚人物与画风；参考图只锚人物与画法，动作、镜头、场景仍由提示词决定；提示词与参考图冲突时提示词优先。

## 1. 开工前（缺一步不许开图）

1. **认领声明**：先在章批次记录顶部写一行「认领：<执行体> <日期>」。同一泳道禁止两个执行体同时跑（来源：ch07 抢道事故）。
2. **当日磁盘重验**：受影响格子的判定，一律以开工当天磁盘上的图与当前提示词重看一遍为准。抽检报告、上一票的 Comments 只作线索——`panel_web` 可能被并行会话覆盖过。
3. **提示词现算**：本批每格的 `prompt_hash` 用 `node tools/panel-ledger.mjs hash <key>` 现取，不接受旧值。
4. **备份检查**：要覆盖的格子确认备份区状态；按指纹命名天然幂等，重复备份不会覆盖已有备份。

## 2. 选参考图

顺序固定，取到即停：

| 级 | 来源 | 取法 |
|---|---|---|
| 1 | 同组 pass 格 | 本游戏四格里 `decision=pass` 且 `status=verified` 的格。多张时取面部与人物占画面比例大的那张（锚的是人物不是构图），落选原因写进批次记录 |
| 2 | 同章最近校准通过图 | 本章批次记录或风格校准记录里判为通过的那张；无记录时取本章台账里 `decision=pass`、`status=verified` 中键号最大的格 |
| 3 | 最新校准通过图 | 全书台账里 `decision=pass`、`status=verified` 按（章号, 键号）最大者。当前为 `034-4`（ch07，7-9 月），复算：`awk -F, 'FNR>1 && $3=="pass" && $9=="verified"{print FILENAME,$1}' reports/panel-ledger/*.csv \| sort \| tail -1` |

**月龄护栏**：参考图的月龄段必须与目标格相同。跨段时只能借它的妈妈与画风，宝宝月龄不锚，盲审须把「宝宝月龄被参考图带偏」列为检查项；目标格既无同组 pass、又无同月龄段可锚时**不锚**，整组转 needs-human 交作者。理由：人物层的宝宝按月龄填，跨段参考图会把 24-36 月画成婴儿。

**参考图文件**：优先书稿仓 `assets/art/panel/<key>.png`（1152×768 原件），缺失时用 `assets/art/panel_web/<key>.jpg`（900×600）；两份都没有就退回上一级。

**冲突**：参考图与提示词冲突时提示词优先（ADR-0003 权威顺序：正文 > 插画脚本 > 数据 > 图片）。参考图不得改变动作、镜头、场景与道具数量。

## 3. 整组生成顺序

1. 组内先出**一张锚定基准**：已有 pass 格就直接用它；没有就先出第 1 格，过了三口径再当基准。
2. 其余格一律锚这张基准，逐格串行（并行写盘会串图）。
3. 基准在生成中途被推翻时停批、重选基准，已出的图留档作废。

## 4. 出图任务单

不产图的准备票（提示词侧票）交付的最小单位是一行一格的任务单：

| 字段 | 含义 |
|---|---|
| key | 步骤图编号 `NNN-K` |
| prompt_hash | 当前拼接提示词的 hash，现算 |
| 参考图 key | 按第 2 节选中的图；不锚写 `none` 并注明原因 |
| 理由码 | 该格重画的理由（A1 场景 / A2 道具 / A3 动作 / A4 月龄 / A5 安全 / A6 禁画项 / A7 画风） |
| 锁定句 | 出图时追加的格内锁定（动作主体、数量、朝向、月龄姿态），没有写 `-` |
| 回填位置 | 落图后写台账的章文件与批次号 |

示例（hash 为占位）：

```text
079-2 | <hash> | 079-1 | A3-action | 宝宝右手握剪、左手捏纸条 | reports/panel-ledger/ch11.csv ch11-b01
```

任务单只描述「出什么图」，不宣称图已存在；落图与盲审属于出图批次。

## 5. 盲审

- 盲审者只看**图 + 提示词**，不看台账、不看旧图、不看任务单里的参考图 key。
- 例行检查项：① 提示词要求的事项是否画出；② **是否被参考图带偏**——动作主体、朝向、场景、道具数量、宝宝月龄是否被参考图的构图替代；③ 禁画项与安全项。
- 盲审记录首行写明本批每格实际使用的参考图 key（回答「这张图的人物像谁」），正文仍按「只看图与提示词」给结论。
- 结论与台账不一致 → 该格转 needs-human，不改结论去迁就台账。

## 6. 三口径并排验收

整组并排看，不看单张：

- **画风一致**：同一种水彩语言、暖米调、吉卜力式动画面部；写实脸混入记 `A7-style`。
- **人物一致**：妈妈发色 / 发型 / 服装 / 体型、宝宝月龄感、道具玩偶造型同组相同；设定外变化（孕妇体型等）记人物项并回写理由码。
- **内容一致**：场景 A1 / 道具 A2 / 动作 A3 / 月龄 A4 / 安全 A5 / 禁画项 A6。

结论按组写一行（组通过，或待重画 + 主导理由码），进章批次记录，不进台账列。

## 7. 记账与回写（出图批次才做）

1. 覆盖前按指纹备份原图；无备份不覆盖。
2. 落图后写台账行：pass 行带磁盘 `new_sha256`；regen 行带新旧两个指纹与批次号。
3. 双仓回写：babyGame `panel_web/*.jpg` + 书稿仓 `panel/*.png` 与 `panel_web/*.jpg`，两仓指纹一致。
4. `npm run check` 0 错误 0 警告收尾。

## 8. 失败处置

单格最多两次尝试；两次都不过转 needs-human，保留原图与历次产物，继续下一格。批次结束时汇总 needs-human。

## 9. 只改提示词的票怎么收

- 不产图、不写台账行；交付第 4 节的任务单与补强后的提示词。
- 提示词一改，该书已有台账行的 `prompt_hash` 立刻过期：同一票里把受影响行的 hash 更新或标为待重比，不许留给下一次校验去发现。
- 收尾仍是 `npm run check` 0 错误 0 警告。

## 10. 纸面演练：116 呼吸小熊

| 格 | 判定 | 参考图 | 理由 |
|---|---|---|---|
| 116-2 | regen A7-style + A4 | 116-1 | 本组唯一 pass 格，同月龄段（24-36 月）。锚它会把 116-1 的偏黑发色一起固定，属已知取舍 |
| 116-3 | regen A1 + A3 | 116-1 | 同上；场景改回卧室躺床，参考图只借人物，不借构图 |
| 116-4 | regen A3 + 人物 | 116-1 | 同上；孕期体型由人物层新增的否决型约束兜底，不靠参考图 |

失败分支：开工时若 116-1 已被覆盖或不再判 pass，按第 2 节第 2 级取同章最近校准通过图；ch15 无校准记录，会落到第 3 级 `034-4`（7-9 月）——此时触发月龄护栏，宝宝月龄不锚，整组转 needs-human。
