# 步骤图提示词目录

520 张步骤图的生成描述文本。这里是唯一来源：书稿项目不再保留副本（ADR-0002）。提示词不进入运行期，网页不读取它，`src/` 里也没有相关代码。

## 目录

| 路径 | 内容 |
|---|---|
| `presets/style.md` | 风格层，520 条共用的固定前缀 |
| `presets/character.md` | 人物层，妈妈固定，宝宝按月龄填 |
| `presets/camera.md` | 镜头词表，5 个 id 与插画脚本写法的对照 |
| `presets/scene.md` | 场景字典，8 类加兜底，每类有 full / brief 两段 |
| `presets/negative.md` | 负面层，四类禁画项合并为一句 |
| `ch05.md` … `ch18.md` | 格层，一章一文件，与游戏章一一对应 |
| `archive/image-prompt-catalog.md` | 迁入前的原总表，只读，用于溯源 |

## 一条提示词怎么拼出来

```
[风格层] + [人物层] + [镜头] + 「，」 + [场景] + 「。」 + [动作] + 「。」 + [道具?] + [负面层]
```

- 镜头与场景在格层只写 id，文案由字典提供。
- 特写与手部特写取场景的 `brief`，其余取 `full`。
- 道具取游戏的器材字段；器材为「无」时整层省略。
- 标点由拼接模板统一补，格层字段不要写结尾句号。

## 一格怎么写

```md
### 006-3　蹬腿自行车｜步骤图 3

- **镜头**：俯拍
- **场景**：客厅
- **月龄**：0-3月
- **动作**：两腿交替，像蹬车；双手随节奏轻推；宝宝笑
- **道具**：无
- **状态**：已复核
```

- 标题固定为 `### 编号　游戏名｜步骤图 N`，编号是三位游戏号加一位图号。
- 字段固定六项：镜头、场景、月龄、动作、道具、状态。月龄冗余存一份，提示词脱离游戏数据也能复现。
- `状态` 只有 `待复核` 与 `已复核`。`待复核` 表示还没人逐条核对过。

## 命令

| 命令 | 作用 |
|---|---|
| `npm run prompt 006-3` | 打印这一格的最终文案 |
| `npm run prompt 006` | 打印该游戏四格 |
| `npm run check` | 全量校验：键与图片双向一致、字典引用、禁画项、月龄对齐 |
| `npm test` | 解析、组合、校验的测试 |

## 改之前先读

- 改动共享层（风格、人物、镜头、场景、负面）会波及全批，改完至少抽查一个游戏的四个步骤图。
- 场景与镜头只能写字典里的值；新增类别要先改字典，再改格层。
- 场景的「兼用」声明粗粒度的共用场地（如「家中」也可归客厅或门厅），它只放宽校验，不改变默认归属。
- 动作句写「看得见的东西」：谁、身体哪部分、朝哪、手在做什么、脸上什么表情。不写心理活动与教学解释。
- 插画脚本里的「标签」和「安全插图」角标是排版文字，不得进入画面描述。
- `archive/` 只读。原总表是迁移前的唯一版本，改了就失去溯源价值。
