# 步骤图提示词复核报告

> **本轮由模型逐条复核，不是人工确认。** 复核者是执行 `.scratch/prompt-review/issues/01`-`11` 的 Agent，判断依据是游戏数据里的步骤、场地与器材字段，以及 `prompts/presets/` 的字典；没有逐张比对既有图片。人工抽检与最终签字仍然要人来做。
> 对象：`prompts/ch05.md` … `prompts/ch18.md`，520 格；基线是第 5 章 40 格（迁移时已复核）。
> 工具：`npm run check`（含本轮新增的「四格至少两项不同」告警）、`npm test`、`npm run prompt <编号>`。

## 五项核对标准

1. **动作对应步骤**：每格的动作落在所属游戏对应的那一步，顺序不打乱；一步跨两格时，两格各自要有不同画面。
2. **场景一致**：场景 id 必须在游戏场地允许的集合内；浴室冷调、餐桌侧窗光，两套光线不互相污染。
3. **道具具体**：写得出数量与品类；器材有、画面没有的不硬写，画面有、器材漏写的补进道具层。
4. **无禁画项**：内容层七项（学步车、脖圈、床围、趴睡、手机哄娃、整粒坚果、蜂蜜）零出现；与负面层「无文字」冲突的步骤（名字卡、签名、线路图、站牌）改写为不含可读文字的画面。
5. **四格有差异**：同一游戏的四个步骤图，在镜头、场景、道具、动作四项里至少两项不同。本轮把这条写成 `tools/prompt-catalog.mjs` 的校验，由 `tools/check-prompts.mjs` 打印。
